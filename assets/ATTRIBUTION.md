# 第三方素材

| 素材 | 来源 | 许可证 |
|---|---|---|
| `ui/scifi/button.png`、`ui/scifi/panel.png` | [Kenney UI Pack](https://kenney.nl/assets/ui-pack) | **CC0**（公共领域，无需署名） |
| `fonts/fusion-pixel-12px-zh_hans.otf` | [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) | **SIL OFL 1.1** |
| `sprites/pixel/enemy_*.png`、`tower.png` | [Kenney Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon) | **CC0**（公共领域，无需署名） |
| `sprites/pixel/icon_life.png`、`icon_gold.png` | [Kenney Micro Roguelike](https://kenney.nl/assets/micro-roguelike) | **CC0**（公共领域，无需署名） |
| `fonts/NotoSansSC-Regular.otf` | [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk) | **SIL OFL 1.1** |

两个都可商用。Kenney 免署名，Fusion Pixel 只要求字体本身不单独售卖、
衍生字体沿用 OFL，嵌进游戏里没有任何限制。

贴图和精灵都做了去饱和处理，运行时靠 `modulate` 染色 —— 属性颜色完全由代码控制，
不会被素材本身的色偏带偏，换配色也不用重新导素材。
